# T13 — Relay, notification tasks, Inbox, and failure recovery

## Context

Orders must succeed even if RabbitMQ is down for a few minutes; notifications catch up later without duplicates (scenario 10). Delivery is at-least-once.

## Exact scope

- Compose: `rabbitmq`, `relay`, `worker` (same backend image, different commands). Persistent queues and messages. Management UI not public.
- Relay: lease/claim in a short transaction; publish named Celery tasks (standard envelope, one mapping, integration test); mark published only after publisher confirm; detect unroutable; no long lock during network I/O.
- Worker: Inbox unique `(consumer_name, event_id)`; create in-app notification + Inbox in one transaction; ack after commit; duplicates do not create a second notification. Automatic Inbox purge **not** enabled (OPEN DECISION).
- Retry: exponential backoff + jitter, max 5 consume attempts. Poison/unknown type → durable `platform.failed_jobs` (sanitized). Do not ack if failure cannot be recorded. Configure `acks_late` and `task_reject_on_worker_lost`; test a killed worker.
- Ops replay command, audited, documented. Do not casually delete Inbox rows.
- Payload: versioned integration events, minimal, no secrets. `traceparent` propagated. Notifications module consumes events and must not mutate orders. List + mark-read APIs: `GET .../notifications`, `POST .../notifications/{id}/read`.
- Frontend notification list if not already done.
- Complete `ADR-005`.
- Keep Outbox bodies ≥30 days for controlled republish (retention job can be documented even if later).

## Acceptance criteria

- Queue stop and recovery neither loses nor duplicates notifications (week-6 exit with T14 scheduler part; scenario 10).
- Replay is documented and audited.
- Duplicate message critical test passes.
- Three cut points: after order before publish; after publish before Relay success; after notification before ack — business result neither lost nor doubled.

## Tests required

- Three cut-point failure tests

- API: list/read notifications, tenant isolation
