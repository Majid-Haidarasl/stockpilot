## Context

The project is done only when the section-29 checklist is complete, evidence exists, and there is no open critical defect in authorization, tenant isolation, stock balance, or restore. Buffer hours are for finishing this scope, not for extra features. Optional email, Tempo, or one postponed feature may be considered only after this list is complete, with a separate estimate.

## Exact scope

- Walk the full acceptance checklist in `AGENTS.md` §26 and record evidence under `docs/evidence/`.
- Fix remaining defects. No critical open issues in permission, isolation, stock balance, or restore.
- Final load, failure (queue/worker), and restore reports; measured release downtime; known limits. Performance and RPO/RTO numbers remain design goals until measured — report actuals; do not retroactively declare unmeasured goals as achieved (OPEN DECISION 4).
- Documentation pack: quickstart (fresh clone on Windows 11 + Docker Desktop, PowerShell commands, no host Python/Node), domain rules, architecture diagrams, ADRs, API contract, deploy guide, failure and restore runbooks, evidence report, version/digest list.
- About a 10-minute demo script: login; two-org isolation; create order; insufficient stock; successful reserve; confirm; ship; stop the queue and still record an order; notifications catch up. Restore drill may stay a separate timed report.
- Demo data via `ops seed-demo` (synthetic only).
- Confirm non-removable critical tests, type checks, architecture contracts, and release scans are green (or a limited justified exception is recorded).
- Delivery artifacts listed in `AGENTS.md` §26 are in the repository.

## Step-by-step implementation notes

1. Follow the quickstart on a **fresh** environment as a real rehearsal, not from a dirty developer volume.
2. Do not drop access control, stock balance, or restore to protect the calendar.
3. Do not invent cost figures or patch versions.

## Acceptance criteria

- Week-8 exit: all v1 criteria complete; evidence, run guides, release version, and full demo ready; no open critical defect.
- Every item of the section-29 checklist is ticked with a pointer to evidence.
- Scenario 12: backup restored in a separate environment; login, order view, and stock-balance check succeed.

## Tests required

- Full critical set still passing
- Final Playwright main path
- Final load and restore evidence (reports, not just “should be fine”)

## Out of scope
