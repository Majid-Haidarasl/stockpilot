## Context

Security scans (pip-audit, Gitleaks, Trivy) belong on the release line; the PM placed them in this week (OPEN DECISION item 11 — implement when the release pipeline is built).

## Exact scope

- CI/CD: build **once** backend and edge images; tag + digest; push to GHCR; promote the **same** digest to staging (not a rebuild). API/worker/relay/scheduler share the backend digest. Default workflow permissions read-only; pin actions; no secrets on untrusted PRs; no credentials in logs.
- `compose.prod.yaml`: no host code mounts, operational secrets, published ports only on Caddy, hardening (non-root, `no-new-privileges`, dropped caps, read-only FS where practical). No Docker socket on app services.
- Release steps documented (backup first, drain processors, migrate with owner role, start, smoke, watch Outbox/scheduler). Expand/Contract reminder. Rollback only if schema/messages compatible; no `down -v` on production.
- Backup: every 12 hours, `pg_dump` of `stockpilot` and `keycloak`, success check, restic encrypt, transfer to an **independent** destination (second host / rest-server is the design-compatible option). Pause identity admin changes during the two dumps. Metadata: snapshot time, schema version, app image version, checksums. Backup role can read through RLS; credential not given to the API. `backup` and `backup-scheduler` services; commercial scheduler does not get backup rights; no Docker socket.
- Retention 14 daily / 3 monthly for **practice** data (OPEN DECISION for real pilot policy). Keys for restic and token decryption are not stored only inside the backup they unlock.
- Restore drill: separate Compose project name, network, and volumes; restore restic → DBs → roles → same app version → login, membership, stock-balance command; invalidate old sessions; do not attach an old queue; replay Outbox controlled; Inbox prevents duplicate notifications. Record elapsed time (RPO 24h / RTO 2h are design goals, not yet measured — OPEN DECISION 4).
- Initial Locust load test (`load-test` service) on the reference scenario in `AGENTS.md` §27 item 4 (or a clearly documented down-scale if hardware is smaller — do not silently change targets). Report numbers with image, hardware, data volume, and scenario. Do not add caches or extra API processes without evidence (OPEN DECISION 8).
- HTTPS public needs domain/DNS/persistent certs — if those are unavailable, document as environment limitation, do not claim public HTTPS.
